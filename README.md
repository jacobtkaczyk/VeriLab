# VeriLab

**VeriLab** is a web-based Verilog IDE and Simulator designed to streamline logic design instruction. It provides a browser-based environment for writing, simulating, and visualizing Verilog code without complex local toolchain configurations, utilizing Icarus Verilog for simulation and a custom waveform viewer.

---

## Prerequisites

Before running VeriLab, ensure you have the following installed on your machine:

- **Node.js & npm** (for the frontend)
- **Python 3.8+** (for the backend)
- **Icarus Verilog** (simulation engine)
  - *macOS:*
    ```bash
    brew install icarus-verilog
    ```
  - *Linux:*
    ```bash
    sudo apt-get install iverilog
    ```
  - *Windows:*  
    Download the installer from the [Icarus Verilog site](http://bleyer.org/icarus/).

## Project Structure

```text
/frontend   # Next.js application (IDE interface & Waveform Viewer)
/backend    # Django application (API & Simulation Orchestration)
```
## Installation & Setup

### 1. Backend Setup (Django)

Navigate to the backend directory and set up the Python environment.

```bash
cd backend

# Create a virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install Python dependencies
pip install -r requirements.txt

# Apply database migrations
python manage.py migrate
```

### 2. Frontend Setup (Next.js)

Navigate to the frontend directory and install the Node modules.

```bash
cd ../frontend

# Install dependencies
npm install
```

## How to Run

You need to run the backend and frontend servers simultaneously in separate terminal windows.

### Terminal 1: Backend Server

```bash
cd backend
source venv/bin/activate
python manage.py runserver
```

The backend API will be available at:

http://localhost:8000

The web interface will be available at:

http://localhost:3000

## Features

### Code Editor
Syntax highlighting for Verilog/SystemVerilog.

### Simulation Engine
Compiles and runs code using `iverilog` on the backend.

### Waveform Viewer
Visualizes VCD (Value Change Dump) files generated by the simulation directly in the browser.

### Error Reporting
Returns compilation and runtime errors directly to the frontend console.
